# 📊 Retail Sales ETL Dashboard

## 📌 Project Overview
This project is a **Retail Sales ETL Dashboard** developed using **Power BI, Excel, Python, and SQL** to analyze retail sales data and generate business insights through interactive visualizations.

---

## 🛠️ Tools Used
- Power BI
- Microsoft Excel
- sql
- Python
- Panda
- ETL Process

---

## 📊 Dashboard Features
- Total Revenue, Orders, Quantity & Profit KPIs
- Revenue vs Profit Analysis
- Year-wise Revenue Trend
- Region-wise Revenue Analysis
- Segment-wise Revenue Distribution
- Category-wise Revenue Insights
- Interactive Date Filter

---

## 📈 Analysis Summary
- Technology category generated the highest revenue.
- West region contributed maximum sales.
- Revenue increased steadily from 2012 to 2014.
- Consumer segment had the highest sales share.
